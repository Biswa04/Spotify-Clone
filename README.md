# Spotify Clone 

A Spotify-inspired music player website built using HTML, CSS, and JavaScript.

## Features

- Browse different music albums.
- Play and pause songs.
- Automatically play the next song when the current song ends.
- Previous and next song controls.
- Interactive seek bar with song duration.
- Volume control and mute option.
- Responsive music player interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON

## How to Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using Live Server.
4. Enjoy listening to music!
